## 1. Внимание публики (Wordstat, Москва и область, по неделям, 30.09.2024 – 04.10.2026)

- Самый большой всплеск интереса к заводу был после пожара: неделя 03.02.2025, 53 429 запросов «Электрозавод»,
  в 36 раз выше обычного уровня (медиана октября 2024 – января 2025: 1 490 в неделю). Факт.
- Пик конфликта: неделя 22.06.2026, 9 112 запросов (×6,1), из них 710 — «Электрозавод снос». На эту неделю
  пришлись ответ компании 24.06 и открытое письмо 25.06; неделей раньше — текст «Архи.ру» 15.06. Факт.
- Третий всплеск: неделя 07.09.2026, 3 777 (×2,5), 377 — «снос». 5–7 сентября жители выкладывали фото и видео
  сноса, 07.09 «Архнадзор» написал «начат снос», 08.09 «Москвич Mag» — о снесённом историческом корпусе. Факт.
- Объявление проекта компанией 15.09.2025 почти не заметили: 1 577 запросов (×1,1). Факт.
- Запросов «Электрозавод Эталон» не больше 106 в неделю. Мы думаем, что публика связывает завод со сносом, а не с
  компанией; проверить это по запросам нельзя.
- После пожара «Электрозавод снос» искали в среднем 20 раз в неделю (12 недель), в спокойный период до утечки —
  3 раза в неделю (57 недель). Это совпадает с H8, но совпадение по времени не доказывает причину.
- Вывод для стратегии: интерес растёт волнами после видимых событий, в первую очередь когда снос виден на фото. Каждый
  следующий видимый шаг (разборка, ограждение, выход техники в марте) даст новую волну. Компании нужно объявлять такие
  шаги заранее, с объяснением, что и почему разбирают.
- Ограничения: Wordstat не различает мотивы поиска; в запрос «Электрозавод» попадают и другие темы (ДК, рынок, лофт).
  Google Trends не использован: только регион «Россия», с 31.07.2026, 75 из 90 дней нулевые.

## 2. Позиции (выборка 1 500 реакций, июнь – октябрь 2026, разметка gemini-3.8-flash)

Выборка: по 400 случайных реакций из YouTube, Telegram, VK и 300 из Дзена, не больше 3 от одного автора, из среза
5 905 реакций на публикации о заводе (D-28, D-35). Модель совпала с эталонной разметкой Claude в 88% из 60 текстов
(каппа 0,81, D-38). Итог по всем площадкам взвешен на размер среза.

- 36% реакций не о заводе (540 из 1 500): политика, другие темы выпусков, перепалки. Факт.
- Из 960 реакций о заводе: против 66% (95% интервал 63–69%), за 9% (7–11%), смешанная позиция 1%, без позиции 24%.
  Факт.
- По площадкам против: VK 73% (67–78), Дзен 66% (59–72), YouTube 65% (59–70), Telegram 61% (55–67). Больше всего
  «за» в Дзене (14%) и на YouTube (11%), меньше всего в Telegram (4%). Факт.
- По месту обсуждения (D-39) против: районные сообщества 73% (67–78, n = 232; 3/4 выборки — VK best_vao),
  городские СМИ 71% (60–79, n = 85), широкая аудитория 64% (60–69, n = 455), градозащитные и москвоведческие каналы
  61% (54–67, n = 188). Факт.
- Самые недовольные — участники районных сообществ. В каналах градозащитников и москвоведов больше всего реакций
  без позиции (35%): там чаще обсуждают детали — корпуса, суды, опись. Это интерпретация.
- Самое большое обсуждение в Telegram (moskvichmag, 365 реакций, три автора написали 313) разобрано отдельно (D-36):
  из 22 текстов о заводе 10 не о нём, из 12 остальных 7 против и 5 без позиции.
- Ограничения: реакция — это сообщение, а не человек и не житель; позиция комментаторов не равна позиции всех
  москвичей. Сарказм отмечен в 14% реакций о заводе; в эталонной проверке модель чаще ошибалась, принимая «против» за
  «без позиции» (5 из 30), поэтому доля противников, скорее всего, немного занижена.

## 3. Линии критики (645 реакций «против» и «смешанных», несколько линий у одной реакции)

| Линия | Доля | Комментарий |
|---|---|---|
| утрата наследия | 50% | главное во всех группах |
| «ради коммерческой застройки» | 25% | в районных сообществах 29%, у градозащитников 8% |
| сговор с городом | 21% | в широкой аудитории 25%, у градозащитников 10% |
| другое | 11% | в основном общая критика властей и застройки Москвы |
| новодел, фасадизм | 4% | у градозащитников 7% |
| нет настоящих обсуждений | 3% | |
| утрата культурных пространств | 2% | |
| нет открытой схемы проекта | 1% | |
| бытовые последствия (стройка, транспорт, плотность для района) | 0,3% | ноль в районных сообществах |

- Вывод: люди говорят об утрате памяти, о деньгах и о сговоре. Отсутствие схемы, на котором держится бриф, сами
  комментаторы почти не называют. Схема нужна как доказательство, но отвечать надо на три главных обвинения.
- H3 не подтверждается: в районных сообществах бытовые темы почти не звучат.
- Ограничение: линии размечены моделью на русском кодбуке; согласие по линиям с эталоном не измерялось, только по
  позиции.

## 4. Доводы сторонников (80 реакций «за», без весов)

Модернизация района 54%, здания в плохом состоянии или после пожара 25%, объявленного к сохранению достаточно 21%,
экономическая польза 9%. Эти доводы уже есть у части аудитории; компании можно опираться на них, не придумывая новые.
